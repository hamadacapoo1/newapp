# نوتس صوتية (VoiceNotes_AIDE)

تطبيق أندرويد بيفرّغ صوتك لنص عربي **أوفلاين ومجاني** (Vosk) ويحفظه كنوت.

## تشغيله في AIDE
1. فك الضغط وانقل مجلد `VoiceNotes_AIDE` للموبايل.
2. افتح AIDE ← Open Project ← اختار المجلد.
3. **شغّل النت** أول بناء: AIDE هينزّل مكتبتين (Vosk و JNA).
4. Run / Build.
5. أول ما تفتح التطبيق: اضغط "⚙ الموديل" ← "تحميل الموديل" (حوالي 330 ميجا، مرة واحدة بس).
6. بعدها "🎙 تسجيل جديد" واتكلم.

## ملاحظات
- التسجيل بيقف لو خرجت من التطبيق أو قفلت الشاشة (أندرويد بيمنع المايك في الخلفية).
- لو خرجت بالرجوع والنص مش فاضي، النوت بتتحفظ تلقائياً.
- الموديل العربي كبير: ممكن يبطّأ الموبايل الضعيف أو يقفل التطبيق لو الرام قليلة.
- دقة العربي أوفلاين متوسطة، والتشكيل وعلامات الترقيم مش موجودة. عدّل على النص قبل الحفظ.
- النسخة الجاية: تفريغ ملفات صوت مرفوعة.
